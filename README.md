# IFRN - TADS: Material de Java

Este repositório contém uma coleção de projetos e exercícios desenvolvidos durante o curso de Tecnologia em Análise e Desenvolvimento de Sistemas (TADS) no IFRN, focados no aprendizado da linguagem Java e Programação Orientada a Objetos (POO).

## 📁 Estrutura do Repositório

O repositório está organizado em diferentes diretórios, cada um representando um projeto ou conjunto de exercícios específicos:

*   **`Algoritmo/`**: Contém implementações de algoritmos clássicos de ordenação, como:
    *   Bubble Sort
    *   Insertion Sort
    *   Merge Sort
    *   Quick Sort
    *   Selection Sort
*   **`Biblioteca/`**: Um sistema de gerenciamento de biblioteca, demonstrando o uso de:
    *   Conexão com banco de dados (`conexao/`)
    *   Interfaces gráficas (`interfaces/`)
    *   Modelos de dados (`model/`)
*   **`Exercicio02_contas_bancarias/`**: Exercício prático focado em POO, simulando operações bancárias com classes e janelas gráficas.
*   **`JavaNote/`**: Projeto de um bloco de notas ou sistema de anotações simples.
*   **`JavaPc/`**: Diversos códigos de aula, exemplos de tratamento de exceções e pequenos projetos de POO.
*   **`ProvaPOO/`**: Resoluções de questões de provas de Programação Orientada a Objetos, abordando temas como classes `Produto` e `Funcionario`.

## ⌨️ Atalhos Úteis (NetBeans)

Visto que os projetos foram estruturados utilizando a IDE NetBeans, aqui estão alguns atalhos que facilitam o desenvolvimento:

| Atalho | Descrição |
| :--- | :--- |
| **`Shift + F6`** | Executa o arquivo (classe) selecionado no momento. |
| **`Ctrl + Space`** | Ativa o preenchimento automático de código (Auto-complete). |
| **`Alt + Insert`** | Abre o menu para gerar código automaticamente (Construtores, Getters/Setters, etc.). |
| **`Ctrl + Shift + I`** | Organiza e corrige as importações de classes. |
| **`sout` + `Tab`** | Gera rapidamente o comando `System.out.println("");`. |
| **`Ctrl + /`** | Comenta ou retira o comentário da linha de código. |
| **`Alt + Shift + F`** | Formata o código fonte automaticamente. |

## 🚀 Como Executar

1.  **Pré-requisitos**: Certifique-se de ter o JDK (Java Development Kit) instalado em sua máquina.
2.  **IDE**: Recomenda-se o uso do **NetBeans IDE** ou **Apache NetBeans** para abrir os projetos, pois os arquivos de configuração (`nbproject/`, `build.xml`) já estão presentes.
3.  **Importação**:
    *   No NetBeans, vá em `File > Open Project`.
    *   Navegue até a pasta raiz deste repositório e selecione a pasta do projeto que deseja abrir.
4.  **Execução**: Localize a classe principal (geralmente `Main.java` ou classes dentro do pacote `janelas` para GUIs) e pressione `Shift + F6`.

## 🛠️ Tecnologias Utilizadas

*   **Java**: Linguagem de programação principal.
*   **Swing/AWT**: Para criação de interfaces gráficas (GUIs).
*   **NetBeans**: Ambiente de Desenvolvimento Integrado (IDE).
